===============================Movelist======================================

Super Jump
 D,U or press three kicks

Black Cat helper
 medium punch + medium kick

Web Ball
 D,DF,F + punch

Web Swing
 D,DB,B + kick

Spider Sting
 F,D,DF + punch

Web Throw
 D,DB,B + punch

Maximum Spider
 D,DF,F + 2 punch

Web Crawler assault
 D,DF,F + 2 kicks

Ultimate Web Throw
 D,DB,B + 2 punches

==================Mode select==================

Hold down the start button while selecting:

Start + button a = Captain Universe/Cosmic Spidey
Start + button b = Symbiote Spidey
Start + button c = Armoured Spidey
